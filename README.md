# VIVAELFUTBOL

Web app multiutente per gruppi, partite, prenotazioni, lista d’attesa, generazione delle squadre, valutazioni separate per gruppo e statistiche.

## App pubblica

https://lorenzo072001-sketch.github.io/vivaelfutbol/

## Stato del progetto

- Frontend collegato a Supabase
- Pubblicazione automatica con GitHub Actions e GitHub Pages
- Installabile dal browser come web app
- Icona personalizzata inclusa

## Ultima configurazione necessaria

Consulta `SETUP_SUPABASE.md` per creare le tabelle e configurare gli URL di autenticazione.

Non caricare mai nel repository password del database, chiavi `service_role` o chiavi `sb_secret_`.
